家族信託 vs 保險:傳承工具嘅結構性比較

同樣係「留俾下一代」,但信託同保險嘅底層邏輯完全唔同 — 用錯工具可能比唔做更差

1. 核心差異:兩種工具嘅底層邏輯

好多人(包括部分從業員)會將「家族信託」同「保險」混為一談,以為兩者都係「留俾下一代嘅錢」。但喺法律結構上,佢哋係完全唔同嘅工具:

🏛️ 家族信託(Trust)

信託係一個法律關係,由三方組成:

  • Settlor(委託人) — 將資產放入信託嘅人
  • Trustee(受託人) — 為受益人持有同管理資產嘅人
  • Beneficiary(受益人) — 最終享受信託資產嘅人

關鍵:信託一旦成立,資產嘅法律擁有權由委託人轉去受託人。委託人由「owner」變成「beneficiary」(可能),完全失去資產控制權。

🛡️ 保險(Insurance)

保險係一份合約:

  • 保單持有人(Policy Owner) — 通常係投保人本人
  • 受保人(Life Insured) — 被保障嘅人
  • 受益人(Beneficiary) — 身故後收取保險金嘅人

關鍵:保單持有人喺生時保留對保單嘅完全控制權,可隨時更改受益人、贖回、甚至轉讓保單。

核心差異一句講晒

信託: 你放棄資產嘅 control,換取結構性嘅傳承安排

保險: 你保留資產嘅 control,身故後自動按受益人結構分配

3. 幾時用家族信託?

3.1 適合使用信託嘅情境

情境 A:資產規模大(>HK$50M)

信託設立成本相對資產規模變得合理。HK$200K 設立費對 HK$50M 資產 = 0.4%,可接受。

情境 B:多代傳承

如果目標係「資產傳 3 代、4 代」,信託可以設立長期條款,例如:

  • 「受益人必須 30 歲以上先可以提取本金」
  • 「信託資產必須保留 50%」
  • 「禁止用於賭博、毒品」

呢啲條款喺遺囑或保險都難以實現。

情境 C:有特殊需要嘅家庭成員

例如:

  • 有特殊需要嘅子女(信託可指定專門嘅照顧安排)
  • 前度婚姻嘅子女(信託可避免現任配偶影響)
  • 未成年孫輩

情境 D:跨境資產

如果資產喺多個國家(香港 + 新加坡 + 英國 + 美國),信託可以統一管理,避免每個司法管轄區都要 probate。

情境 E:資產保護

如果你嘅業務有訴訟風險(醫生、建築師、董事),信託可以將部分資產保護起嚟,避免被追討。

3.2 唔適合用信託嘅情境

  • 資產規模細 (
  • 短期目標 — 信託係長線工具,短期 5 年內唔化算
  • 唔願意放棄控制權 — 設立後你唔再係 owner
  • 家庭簡單 — 一夫一妻 + 2 個子女,保險或遺囑已足夠

4. 幾時用保險?

4.1 適合使用保險嘅情境

情境 A:家庭基礎保障

人壽保險 + 危疾 + 醫療,係任何家庭嘅基礎保障。建議配置:

  • 壽險: 年收入 5-10 倍保額
  • 危疾: 年收入 3-5 倍保額
  • 醫療: 高端醫療 (HK$10M+ 保額)

情境 B:中產傳承

資產 HK$5M - 50M 嘅家庭,可以用儲蓄保險 + 美元保單作為主要傳承工具。原因:

  • 成本低(只有保費)
  • 保險金直接賠受益人,無 probate
  • 可以分期提取或一次性
  • 保留保單持有人控制權

情境 C:流動性需求高

信託一旦設立,提取要經受託人,可能要幾個星期。保險贖回通常 5-10 個工作天。

情境 D:跨境稅務考慮

某些國家對保險金有稅務優惠:

  • 香港: 人壽保險金完全免遺產稅
  • 美國: 適當結構下可避所得稅
  • 新加坡: 不超過指定門檻免遺產稅

情境 E:退休規劃

儲蓄保險 + 年金可作為退休收入嘅一部分,穩定派發,無市場風險。

4.2 保險嘅局限

  • 保額上限: 一般 HK$30M - 50M 上限,再大要分拆
  • 結構限制: 唔可以設複雜嘅條件(例如「30 歲前不得提取」)
  • 遺產稅未必全免: 視乎國家同保單結構
  • 保險公司風險: 信託嘅受託人破產機會低,保險公司理論上有可能

5. 組合策略:信託 + 保險

最高級嘅傳承規劃唔係「揀信託定保險」,而係「兩個都用」。

5.1 典型組合結構

客戶(個人)
├── 香港自住物業(直接持有)
├── 銀行存款(直接持有)
├── 海外物業(個人 + 太太 50:50)
│
└── 新加坡家族信託
    ├── BVI 公司股權
    ├── 美元儲蓄保險 (保單持有人 = 信託)
    │   ├── 受益人:客戶 + 太太 + 子女
    │   └── 保額:USD 5M
    ├── 香港儲蓄保險(保單持有人 = 信託)
    │   └── 保額:HK$ 10M
    └── 現金儲備(新加坡銀行)

5.2 組合嘅好處

好處 1:靈活性最大化

  • 信託提供結構性保護(資產保護、避免 probate)
  • 保險提供流動性同稅務效益
  • 兩者結合 = 結構 + 靈活 + 成本效益

好處 2:分散受託人風險

唔同嘅資產放喺唔同嘅結構:

  • 流動資產 → 信託
  • 人壽保障 → 保險
  • 物業 → 有限公司

任何一個結構出問題,其他結構仍然運作。

好處 3:不同階段嘅調整

人生唔同階段需要唔同嘅比重:

階段信託比重保險比重
35-45 歲(資產累積期) 低 (20%) 高 (80%) - 家庭保障為主
45-55 歲(資產成熟期) 中 (50%) 中 (50%) - 兩者並重
55-65 歲(傳承準備期) 高 (70%) 中 (30%) - 結構性傳承為主
65+ 歲(退休 + 傳承執行) 高 (80%+) 低 (20%) - 保險已賠完

6.3 綜合比較

表面上保險「成本」高過信託,但實際上:

  • 保險: 付出嘅保費換取保額,有 death benefit 倍數效應(可能 3-5x)
  • 信託: 付出嘅費用換取結構性保護,資產規模唔變

換言之:保險有「槓桿」,信託無「槓桿」。保險成本表面高但實際可能化算(因為賠多過交);信託成本低但只係保護資產唔會增加。

7. 常見錯誤

❌ 錯誤 1:將保險當信託

「我買咗儲蓄保險就等於有信託架構喇」 — 唔係。保險只係賠錢,唔提供結構性保護、資產隔離、長期條款。

❌ 錯誤 2:將信託當保險

「我設咗家族信託就唔使買人壽保險喇」 — 唔係。信託唔會喺你突然過身時提供流動資金,可能造成 family 短期資金壓力。

❌ 錯誤 3:盲目追求「高端」

資產規模 HK$10M 卻要設多層信託 + 私人基金會,結果每年管理費食掉 2% 嘅回報。結構唔係越複雜越好。

❌ 錯誤 4:忽視跨境稅務

喺香港設信託但子女喺英國,結果英國 IHT 40% 一刀切。跨境傳承要考慮每個國家嘅稅法。

❌ 錯誤 5:延誤

「我仲後生,等 60 歲先算」 — 但 50 歲身體可能出問題,屆時買唔到保險、設唔到信託。最佳時間係「資產成熟、身體健康、腦筋清晰」嘅時期。

❌ 錯誤 6:忽略家庭動態

信託 / 保險一設就 30-50 年,但家庭會變:離婚、新生兒、子女事業失敗⋯⋯ 需要定期 review 同調整。

8. 決策框架

用以下問題順序幫自己決定:

📋 Step 1:資產規模

  • 基本保險 + 遺囑已足夠
  • HK$5M - 50M: 保險為主 + 考慮信託
  • >HK$50M: 信託 + 保險組合
  • >HK$200M: 完整家族辦公室結構

📋 Step 2:家庭結構

  • 簡單家庭(配偶 + 子女):保險為主
  • 複雜家庭(前配偶子女、特殊需要子女):信託較適合
  • 多代同堂:信託 + 教育/激勵條款

📋 Step 3:跨境程度

  • 單一國家:保險 + 遺囑
  • 2 個國家:信託較化算
  • 3+ 個國家:必須信託

📋 Step 4:控制意願

  • 願意放手:信託
  • 想保留控制:保險 + 監護人安排
  • 兩者都要:組合策略

📋 Step 5:成本預算

  • 年成本 < 0.5% 資產:可考慮信託
  • 年成本 > 2% 資產:信託結構過複雜,要重新設計

總結

信託同保險唔係二揀一,而係兩種互補嘅工具:

  • 保險: 槓桿、流動性、簡單、保留控制
  • 信託: 結構、保護、長期、靈活分配

最高級嘅策略係根據你嘅資產規模、家庭結構、跨境程度、控制意願同成本預算,度身訂造組合。

記住:工具係手段,傳承嘅目的係「保護家庭同延續價值」。選擇啱嘅工具,先至真正服務到呢個目的。
